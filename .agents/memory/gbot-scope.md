name: The G-Bot scope
description: User-stated initial scope for the Pocket Option utility.
---

The G-Bot currently runs as a one-shot CLI: connect with a demo-account session, print the balance, fetch the latest 50 one-minute EURUSD_otc candles, print the last closed candle, and exit. No web server is in scope yet.

**Why:** The user explicitly limited the first build to a script and said there should be no web server yet.

**How to apply:** Keep future changes CLI-only unless the user asks to expand the product.
